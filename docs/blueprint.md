# **App Name**: Eternal Orbit

## Core Features:

- 3D Galaxy Visualization: Display a 3D galaxy scene with the Earth and Sun.
- Orbital Simulation: Implement orbital mechanics for Earth's rotation around the Sun, and comets rotating Earth
- Interactive Camera: Enable interactive camera controls for zooming and rotation within the 3D space.
- Customizable Comets: The rings of the Earth must be comets. User should be able to click to assign image URL to specific comets to embed girlfriend's photo
- Export Functionality: User should be able to save the image with a transparent background

## Style Guidelines:

- Primary color: Deep space blue (#24292E) to create a sense of vastness and depth.
- Background color: Very dark gray (#121417) to simulate deep space.
- Accent color: A vivid, starlight yellow (#FDD262) to highlight the sun, Earth, and memory comets.
- Font: 'Inter', a grotesque-style sans-serif font, for any informational overlays. 
- Use minimalist icons for camera controls (zoom, rotate).
- Center the 3D galaxy visualization with unobtrusive UI elements overlayed at the corners.
- Implement smooth transitions and subtle animations for camera movements and comet orbits.
